1
EXCEL HANDS-ON
Build the PivotTable
12 MIN
  • 1 Click any cell inside the clean data table. Excel detects the full range automatically.
  • 2 Insert → PivotTable → New Worksheet. Click OK. A blank PivotTable opens with the field list on the right.
  • 3 Drag Product Type to the Rows area. You should see: Deposit, Credit, Investment.
  • 4 Drag Segment to the Columns area. You should see: Retail, SME, Affluent, Seniors.
  • 5 Drag Revenue to the Values area. Check it says "Sum of Revenue" — not "Count of Revenue." If it shows Count: right-click the field → Value Field Settings → Summarize by: Sum.
  • 6 Right-click any value → Number Format → Number → 0 decimal places → tick "Use 1000 Separator".
RESULT You now have a matrix showing revenue for each combination of Product Type (rows) and Customer Segment (columns), with row and column grand totals.
2
EXCEL HANDS-ON
Insert PivotChart
8 MIN
  • 1 Click any cell inside the PivotTable. This links the chart to this specific pivot.
  • 2 PivotTable Analyze tab → PivotChart. (Or: Insert → PivotChart → PivotChart.)
  • 3 Select Clustered Bar from the chart types. Click OK.
  • 4 Right-click the field buttons on the chart → Hide All Field Buttons.
  • 5 Click the chart title and rename it: Revenue by Product Type and Segment.
WHY CLUSTERED BAR? A Clustered Bar chart places product types on the vertical axis and groups each segment as a colour-coded bar per row — making cross-segment comparison easy to read at a glance.
3
EXCEL HANDS-ON
Add Slicers
10 MIN
  • 1 Click any cell inside the PivotTable. PivotTable Analyze → Insert Slicer. Tick Segment and Month (or Transaction Date). Click OK.
  • 2 Position the two slicers beside your chart. Resize as needed.
  • 3 Connect slicers to the chart: Right-click the Segment slicer → Report Connections. Tick both the PivotTable and the PivotChart. Repeat for the Month slicer.
  • 4 Test: click Retail only. Watch the chart update. Then try Affluent + SME together (Ctrl+click for multi-select).
IMPORTANT If the slicer only filters the table but not the chart, Report Connections has not been set. Right-click the slicer and complete the connection step.

Power BI Facilitator Demo · 20 minutes
This section is a facilitator demo

You are watching, not building. Use this page as a reference for what was shown. The key outcome is understanding when Power BI adds value beyond Excel — not learning to build Power BI reports independently.

PHASE A
Load the same dataset
5 min
Home → Get Data → Excel Workbook. Select the clean orders sheet. Click Load (not Transform — the data is already clean from Module 4A). The same five columns appear in the Fields pane: Transaction Date, Product Type, Segment, Region, Revenue.
PHASE B
Build the equivalent visual
10 min
  • Select Clustered Bar Chart from the Visualizations pane.
  • Drag Product Type to Y-axis, Revenue to X-axis, Segment to Legend. Power BI creates the same grouped view as the PivotChart.
  • Add a Slicer visual → drag Segment to the field. Four buttons appear automatically.
  • Add a second Slicer → drag Transaction Date. Set it to show by Month.
  • Note: no Report Connections step required — all visuals on the page filter together automatically.
PHASE C
The interactivity difference
5 min
What was demonstrated:
  • Cross-filter: clicking a bar in the chart cross-highlights all other visuals on the page automatically — no setup required.
  • Slicer auto-filter: clicking a slicer button filters every visual simultaneously.
  • Drill-through: right-click a bar → Drill through → see transaction-level detail behind that segment/product combination.
  • Tooltip: hovering a bar shows multiple configured metrics (revenue, count, average) in one tooltip.

Decision Guide Excel vs Power BI — When to Reach for Each

Both tools answered the same question today. The difference is in what happens after you answer it — and who needs to interact with the result.

USE EXCEL WHEN
✓ You need a quick one-off answer and you're already in Excel
✓ The output is a file attachment — one recipient, one use
✓ Dataset is small (<100k rows) and self-contained
✓ No Power BI licence or IT approval required
✓ Slicers and a single chart are sufficient interactivity
USE POWER BI WHEN
✓ Multiple stakeholders need to view and interact with the same data
✓ Data refreshes on a schedule — connected to live source systems
✓ Cross-filter, drill-through, and multi-visual dashboards are needed
✓ The report is published to a shared workspace — not emailed as a file
✓ Multiple datasets from different sources need to be combined
The Decision Frame
Who is the audience? How often does the analysis run? How many different cuts of the data will you need?
One person, once, flexible format → Excel. Multiple people, recurring, standardised view → Power BI.
